# Développement Frontend Moderne

## Objectifs du cours

Ce cours a pour objectif de fournir une **compréhension solide des pratiques modernes du développement frontend**, en
associant **manipulation directe du DOM**, **programmation orientée composants** et **outils actuels comme React et
Next.js**.

À la fin du cours, les étudiants seront capables de :

- Manipuler dynamiquement le **DOM** avec JavaScript moderne.
- Créer des composants encapsulés avec les **Web Components**.
- Développer des interfaces interactives en **React.js**.
- Organiser une application selon les principes de l’**Atomic Design**.
- Construire un site dynamique et optimisé avec **Next.js**.
- Appliquer ces compétences dans un **projet concret avec évaluation finale**.

---

## Organisation du cours

Le cours est réparti sur **trois jours**, avec une montée progressive en complexité :

### **Jour 1 : DOM & Web Components**

- **Rappels sur le DOM et les événements JavaScript.**
- **Manipulation dynamique du DOM avec les APIs modernes.**
- **Shadow DOM, Templates, Slots : encapsulation du rendu.**
- **Création de composants personnalisés avec Web Components.**
- **Travaux pratiques : création de composants réutilisables.**

### **Jour 2 : Introduction à React**

- **Pourquoi React ? Avantages et cas d’usage.**
- **JSX, composants fonctionnels, props, state.**
- **Hooks de base : `useState`, `useEffect`.**
- **Communication entre composants.**
- **Travaux pratiques : mini-application React dynamique.**

### **Jour 3 : Atomic Design & Next.js**

- **Présentation de l’Atomic Design : structurer un design system.**
- **Introduction à Next.js : routage, pages dynamiques, data fetching.**
- **Organisation d’un projet frontend moderne.**
- **Travaux pratiques longue durée : mini-projet structuré.**
- **Évaluation finale : projet noté avec restitution individuelle.**

---

## Évaluation finale

L’évaluation se compose d’un **mini-projet individuel** à réaliser en Next.js avec :

- Une structure de composants en **Atomic Design**.
- Récupération de données depuis une API.
- Une page dynamique et des composants réutilisables.
- Un court **questionnaire technique** pour valider les acquis.

**Durée de l’évaluation : 1h30 – Note sur 60 points.**
